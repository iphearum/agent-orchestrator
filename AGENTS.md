# Repository instructions

## Progress notes

- Record each meaningful work update as a short, timestamped note in an appropriate `docs/*.md` file. Use `docs/progress.md` as the default log.
- Put the newest note at the top, directly below the document heading. Preserve older notes.
- Use local time with an explicit UTC offset and a compact format such as `2026-09-29 21:43 +07 [docs] Created progress log.`
- Keep notes brief: a few keywords and the outcome are enough. Do not edit unrelated documentation just to add a progress note.
