# Test workspace

Sandbox project opened by the "Run Extension (test workspace)" launch configuration.
Agents read and write files here, not in the extension's own source.

Try: *"POST /api/auth/login returns 500 for unknown emails after the users-table migration. Find the cause in src/auth/login.py and fix it."*

`.vscode/settings.json` holds the model endpoint and API key and is gitignored.
