# Contributing

Thanks for your interest in improving Agent Orchestration Studio.

## Development setup

1. Install [Bun](https://bun.sh/) and a supported version of Visual Studio Code.
2. Clone the repository and run `bun install` from the repository root.
3. Open the repository in VS Code and press **F5** to launch the Extension Development Host.

Useful commands:

- `bun run compile` — compile the extension and webviews.
- `bun run package` — compile and create a VSIX package.

## Pull requests

- Keep changes focused and describe the user-visible effect.
- Include steps to reproduce and screenshots for visible UI changes.
- Update documentation and settings descriptions when behavior or configuration changes.
- Never commit API keys, tokens, local databases, or generated build output.
- Describe any verification you performed and any known limitations.

For bugs and feature requests, open an issue at [GitHub Issues](https://github.com/iphearum/agent-orchestrator/issues).
